## DESKRIPSI
Repositori ini dibuat untuk memenuhi Tugas 3 - Git Collaboration Practice pada mata kuliah Software Development. Fokus utama dari proyek ini adalah mempraktikkan alur kerja kolaborasi tim menggunakan Git dan GitHub, yang mencakup manajemen branch, kontribusi antar anggota, serta proses review melalui Pull Request.

Tujuan dari proyek ini adalah agar setiap anggota tim memahami cara bekerja dalam satu codebase yang sama secara efektif tanpa mengganggu kode satu sama lain.
